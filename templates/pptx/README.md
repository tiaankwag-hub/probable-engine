# templates/pptx

PowerPoint template files (`.pptx`) used by `packages/reporting` — a 1-slide and a 2-slide
ELT template with named placeholders for KPI strip, heatmap, top risks, narrative, "what
changed", spotlight risks, decisions, and immediate actions. Application code fills
placeholders; it does not position shapes.

Status: no templates yet. Planned for Milestone 5.
